## 🚨 Email Breach क्या है?

Email breach एक security incident है जहां unauthorized users आपके email account तक पहुंच प्राप्त करते हैं।

### Common Types of Email Breaches:

1. **Credential Theft (साख चोरी)**
   - Phishing attacks के माध्यम से passwords चुराए जाते हैं
   - Weak passwords का दुरुपयोग

2. **Data Leaks (डेटा रिसाव)**
   - Server हacking के कारण personal data expose होता है
   - Unsecured databases से information चली जाती है

3. **Malware/Spyware (मालवेयर)**
   - Keyloggers द्वारा typed information record किया जाता है
   - Spyware account credentials को monitor करता है

4. **Man-in-the-Middle Attacks (MITM)**
   - Unsecured networks पर traffic को intercept किया जाता है
   - Email communication को eavesdrop किया जाता है

## 🛡️ Email Breach की पहचान कैसे करें?

### Warning Signs:

✓ Unusual login activity से notifications  
✓ Unknown devices से access  
✓ Changed password या recovery options  
✓ Missing या forwarded emails  
✓ Identity theft या fraud के संकेत  
✓ Spam emails भेजे जा रहे हैं आपके खाते से  
✓ Account से locked out हो गए  

### Check करने के लिए Resources:

- **HaveIBeenPwned.com** - Check if your email is in known breaches
- **Google Account Security Checkup** - review your Google account
- **Microsoft Account Security** - check your Microsoft account

## 🔐 Email Breach से बचाव के उपाय

### 1. **Strong Password Strategy**

```
✓ Minimum 12+ characters
✓ Mix of uppercase, lowercase, numbers, symbols
✓ Unique passwords for each account
✗ Personal information (birthday, names)
✗ Dictionary words or common phrases
```

### 2. **Two-Factor Authentication (2FA) Enable करें**

**फायदे:**
- Even if password compromised हो तो account safe रहता है
- Extra security layer provide करता है
- Multiple methods available: SMS, Email, Authenticator app, Security keys

**Setup करने के लिए:**
```
Gmail → Security → 2-Step Verification
Outlook → Security Settings → Advanced security options
```

### 3. **Email Forwarding को Monitor करें**

- Settings में check करें कि कोई unauthorized forwarding rules तो नहीं
- Regular basis पर connected apps को review करें
- Third-party app access को revoke करें जो use नहीं कर रहे

### 4. **Regular Password Changes**

- हर 3 महीने में password change करें
- Breach notification मिले तो तुरंत change करें
- Recovery options को updated रखें

### 5. **Secure Email Practices**

```
DO:
✓ Suspicious links को click करने से पहले सोचें
✓ Unexpected attachments को verify करें
✓ Official websites से directly login करें
✓ Public WiFi पर email access avoid करें
✓ Browser को updated रखें

DON'T:
✗ Public devices से sensitive accounts access न करें
✗ Unknown senders को personal info न दें
✗ Urgent requests पर विश्वास न करें
✗ Weak passwords का use न करें
```

### 6. **Device Security**

- Updated antivirus software रखें
- Operating system को regularly update करें
- Browser extensions को verify करें
- Public WiFi पर VPN का use करें

## 📋 Email Breach होने पर क्या करें?

### Immediate Actions (तुरंत करें):

1. **Password Change करें**
   ```
   Gmail/Yahoo/Outlook account में login करें
   Security settings में जाएं
   Immediately password change करें
   ```

2. **2FA Enable करें**
   - अगर पहले से enable नहीं है तो करें

3. **Recovery Information Update करें**
   - Recovery email address change करें
   - Phone number update करें
   - Recovery codes को save करें

4. **Connected Accounts को Review करें**
   - Third-party app access को check करें
   - Suspicious apps को remove करें
   - OAuth permissions को revoke करें

5. **Active Sessions को Sign Out करें**
   ```
   Google Account: Security → Your Devices
   Microsoft: Security → Device Security
   ```

### Follow-up Actions (अगले दिन):

1. **Credit & Financial Monitoring**
   - Credit report को check करें
   - Bank statements को monitor करें
   - Fraud alerts को enable करें

2. **Contact Relevant Services**
   - Email provider को breach report करें
   - FTC को identity theft report करें
   - Affected websites को notify करें

3. **Monitor Email Activity**
   - Regular basis पर login history check करें
   - Unusual activity को track करें
   - Security alerts को enable रखें

## 🚀 Best Practices Summary

```
1. PREVENTION > REACTION
   - Strong passwords maintain करें
   - 2FA हमेशा enabled रखें
   - Software को updated रखें

2. AWARENESS बनाए रखें
   - Phishing attempts को identify करें
   - Suspicious activity को report करें
   - Security news को follow करें

3. MONITORING करते रहें
   - Regular account checkups करें
   - Credit को monitor करें
   - Security alerts को enable रखें
```
